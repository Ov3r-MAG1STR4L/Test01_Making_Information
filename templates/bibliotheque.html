1. HTML page structure

Every HTML page follows the same skeleton. <head> holds information about the page, <body> holds what the visitor sees.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My page</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <header><h1>Title</h1></header>
    <main><p>Content</p></main>
    <footer><p>Footer</p></footer>
  </body>
</html>

4. CSS rule syntax

A CSS rule = a selector (what to style) + declarations between braces. Each declaration is property: value;

.perso1 {
  font-size: 20px;
  border: 2px solid black;
}
/* this is a CSS comment */

8. Three ways to link CSS to HTML

Inline

In the style attribute. One element only.

<h1 style="color:red;">

Internal

In a <style> tag in the <head>. One page only.

<style> h1 { color:red; } </style>

External (best)

In a .css file linked with <link>. Shared by every page.

<link rel="stylesheet" href="style.css">

Priority if rules conflict: inline > internal/external (the last one read wins) > browser default. This is the "cascade" in Cascading Style Sheets.

9. VS Code quick start

  1. Open a folder: File → Open Folder → choose or create your project folder.
  2. Create a page: New File → name it index.html.
  3. Get the skeleton: type ! then press Tab: VS Code writes the HTML5 structure.
  4. Create the style sheet: New File → style.css, then link it in the <head>.
  5. Save: Ctrl + S (enable File → Auto Save to save automatically).
  6. Test: double-click index.html in your file explorer, or install the Live Server extension → right-click → "Open with Live Server" (page refreshes on each save).
  7. Debug: in the browser, press F12 to inspect HTML and CSS.
  8. Format the code: Shift + Alt + F.
